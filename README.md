# Gesture Recipe Navigation

A hands-free recipe reader prototype. Show a hand gesture to your webcam to scroll or zoom the page — no need to touch the laptop with messy hands while you cook.

## Gestures

| Gesture | Action |
| --- | --- |
| 👍 Thumbs up | Scroll up |
| 👎 Thumbs down | Scroll down |
| ✊ Closed fist | Zoom in (repeats while held) |
| 🖐 Open palm | Zoom out (repeats while held) |

Hold each gesture steadily for about half a second so it doesn't fire accidentally.
