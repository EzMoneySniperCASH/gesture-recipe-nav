# Sample evaluation session logs

Synthetic logs matching the format exported by **Save session log** in the Chrome extension. Use for assignments, charts, or analysis examples.

| File | Participant | Site | Story |
|------|-------------|------|--------|
| `gesture-log-p1-*.json` | p1 | Food Network | Smooth session, medium sensitivity, high confidence |
| `gesture-log-p2-*.json` | p2 | AllRecipes | Heavy scrolling, quick double-scrolls, burst zoom |
| `gesture-log-p3-*.json` | p3 | Serious Eats | Lower scores, slow/light sensitivity, many zoom steps |
| `gesture-log-p4-*.json` | p4 | BBC Good Food | Careful navigator, fewer fires, tuned scroll down |

**Sensitivity scale (1–5):** scroll distance, zoom amount, zoom speed — default Medium = 3.

These are illustrative data, not recordings from live sessions.
